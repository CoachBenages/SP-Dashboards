Load Recalibration

Weekly checks only show trend — they never change the fixed load. Recalibrate at the end of each ~3-week block using this table. Targets: Squat 70%1RM (0.65 m/s) · Bench 75%1RM (0.50 m/s). Bump UP when cumulative Est.1RM gain is ≥8% since baseline or velocity has drifted ≥0.08 m/s faster than target. Bump DOWN when velocity is ≥0.08 m/s slower than target — but if that's paired with a 2-week decline flag, rule out illness, sleep, snap counts, or technique before assuming it's a real strength drop. Otherwise: Hold the current load.
